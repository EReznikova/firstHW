# Шпаргалка по git

## Для локального репозитория нужно:

**1) Инициировать репозиторий**

- Создать папку на компьютере для локального репозитория
- Выполнить `git init` в ней *(если нужно "разгитить" папку, то:* `rm -rf .git`*)*

**2) Добавить файлы, для которых нужен контроль версий**

- Создать файлы в папке репозитория
- Команда `git status` покажет состояние репозитория (что добавлены новые файлы)
- Выполнить `git add <имя файла>` для каждого файла или `git add --all` для всех сразу
- Сохранить изменения в истории `git commit` - теперь при необходимости к ним можно «откатиться»
- Просмотреть историю коммитов можно командой `git log`

*Отличие* `git add` *от* `git commit`*:*
*Сначала команда* `git add` *сообщает Git, какие именно файлы нужно сохранить и какую их версию. Затем с помощью команды* `git commit` *происходит само сохранение*

## Для удаленного репозитория нужно:

- Создать/зайти в свой профиль по ссылке *[https://github.com/username](https://github.com/username)*, где username — имя пользователя.
- На вкладке **Repositories** нажать на зелёную кнопку **New**
- Ввести название и нажать **Create repository**

## Для связи локального и удаленного репозитория нужно:

**1) Сгенерировать SSH-ключи**

- `ssh-keygen -t ed25519 -C "электронная почта, к которой привязан аккаунт на GitHub"`  
- Указать место хранения ключей `Enter a file in which to save the key (/Users/you/.ssh/id_rsa): [Press enter]` 
- Ввести кодовую фразу, но можно без нее
- **Итог:** два файла — один с расширением .pub, другой — без

 **2) Привязать SSH-ключ к GitHub**

- Cкопировать содержимое ключа в буфер обмена для ed25519 `pbcopy < ~/.ssh/id_ed25519.pub`
- Перейти на **GitHub** и выбрать пункт **Settings** в меню аккаунта.
- В меню слева нажать на пункт **SSH and GPG keys**
- В открывшейся вкладке выбрать **New SSH key**
- В поле **Title** написать название ключа
- В поле **Key type** должно быть **Authentication Key** 
- В поле **Key** скопируйте ваш ключ из буфера обмена
- Провеить правильность ключа с помощью `ssh -T git@github.com`

**3) Привязать удалённый репозиторий к локальному**

- Перейти на страницу удалённого репозитория, выбрать тип SSH и скопировать URL `git@github.com:%ИМЯ_АККАУНТА%/%НАЗВАНИЕ_РЕПОЗИТОРИЯ%.git` 
- Выполнить в консоли в папке локального репозитория `git remote add origin git@github.com:%ИМЯ_АККАУНТА%/%НАЗВАНИЕ_РЕПОЗИТОРИЯ%.git` 
- Убедиться, что репозитории связаны ```git remote -v```

**4) Отправить изменения на удалённый репозиторий**
```git push```
